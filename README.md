# María Fernanda Tabera Bazán — Portfolio

Landing page personal construida con **Web Components nativos usando LitElement** (`<skill-chip>`, `<timeline-item>`), sin frameworks pesados ni build step — solo HTML, CSS y un `<script type="module">` que importa Lit desde CDN.

## Ver en vivo

Una vez publicado con GitHub Pages (ver abajo), estará disponible en:
`https://<tu-usuario>.github.io/fernanda-portfolio/`

## Stack

- HTML5 · CSS3 · JavaScript ES6+
- [Lit](https://lit.dev) / LitElement (vía CDN, sin build)
- Web Components nativos

## Editar localmente

Solo abre `index.html` en el navegador — no requiere `npm install` ni build.
